# geni-uploader

A personal, user-run command-line tool for uploading source documents to
Geni profiles and verifying successful uploads.

The tool runs as a container image on the user's own machine. Source code,
image build and usage:
[github.com/reihlinstinct/geni-uploader](https://github.com/reihlinstinct/geni-uploader)
